# Formalization dependency map

```text
finite binary sum/min trees
  -> monotonicity, homogeneity, concavity
  -> normalized-leaf Jensen inequality
  -> block submultiplicativity m_(n+k) <= m_n m_k
  -> Fekete speed rho = inf m_n^(1/n)                 [partial core]

decreasing integrable profiles
  -> exact first/second moment identities
  -> anti-correlation C(Q)M(Q) <= A(Q)S(Q)
  -> normalized second-moment invariant               [partial core]
  -> compact normalized profile set K_p               [major analysis]

quantile one-step operator T_p
  -> L1/Wasserstein continuity                         [major analysis]
  -> normalized map N_p on K_p
  -> perturbed Schauder fixed point                    [major analysis]
  -> limiting eigenprofile T_p Q_p = rho Q_p
  -> Collatz--Wielandt formulas                        [headline]
  -> invariant-measure and ergodic-dual formulas       [extension]
```

Stage 1 stops after the two nodes marked `partial core`.
