# Release notes for Version 1.0.0

## Headline

For every fixed \(p\in(1/2,1)\), the random series-parallel expected-distance
growth factor is the attained maximal eigenvalue of an explicit homogeneous
sum/min operator on normalized quantile profiles. The same value is given by
matching lower and upper Collatz--Wielandt formulas and a compatible
invariant-measure variational formula.

Prior work supplies the critical endpoint \(\delta(1/2)=0\), and the
all-series endpoint \(\delta(1)=\log 2\) is elementary. The Version 1.0.0
contribution is the all-interior model-specific characterization, not a new
generic nonlinear Perron--Frobenius theorem.
