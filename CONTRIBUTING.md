# Contributing

Contributions should improve correctness, scope, provenance, reproducibility,
or formalization.

For a mathematical change:

1. identify the exact theorem, equation, and artifact hash;
2. state whether the change is mathematical or expository;
3. supply an independent derivation or literal counterexample;
4. preserve old versions instead of overwriting them;
5. update the claims matrix and dependency map;
6. re-audit every changed mathematical dependency;
7. regenerate and verify the checksum ledger.

Any change to leaf normalization, the second-moment invariant, compactness,
the Schauder extraction, or spectral comparison requires renewed hostile
audit. Metadata-only changes still require integrity and private-data scans.

Do not infer authorship, affiliation, priority, peer review, DOI, or license
from repository ownership or AI involvement.
